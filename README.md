# Employee Task & Daily Work Report Management System

## Tech Stack
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MySQL
- Sequelize
- JWT Authentication

## Features
- Login / Signup
- Manager & Employee Roles
- Task Assignment
- Task Status Updates
- Daily Reports
- Dashboard Summary

## Run Backend

cd backend
npm install
npm run dev

## Run Frontend

cd frontend
npm install
npm run dev
